ZOMDROID OPT-LAB R9 — UI TABS + INDEPENDENȚĂ MODULE
Data: 2026-08-29

SCOP
====

Acest checkpoint reorganizează interfața OPT-LAB pentru lista viitoare de
optimizări. Nu modifică algoritmii Pathfinding sau PopMan și nu integrează
JAssimp.

UI
==

- se păstrează AlertDialog-ul existent, nu se introduce o activitate cu aspect diferit;
- se păstrează tema Material a aplicației și accentul portocaliu;
- culorile sunt moștenite din temă, deci funcționează automat light/dark;
- șase taburi scrollabile: Overview, Runtime, Display, Build 42, Native, Experimental;
- Overview afișează numai profilul și rezumatele modulelor;
- Runtime și Display conțin opțiunile generale existente;
- Build 42 și Native păstrează ferestrele detaliate existente;
- Experimental este rezervat explicit optimizărilor viitoare și nu simulează funcții active.

INDEPENDENȚĂ
============

- fostul Master OPT-LAB este acum masterul general Runtime/Display;
- OFF la masterul general nu dezactivează și nu șterge Build 42;
- profilurile generale nu modifică Pacing/Stream/FBO;
- presetările Build 42 nu activează și nu modifică Runtime/Display;
- Native Modules rămâne complet independent;
- schema preferințelor OPT-LAB crește de la 4 la 5.

EXPERIMENTAL
============

- Pathfinding Native este etichetat EXPERIMENTAL din cauza regresiei raportate:
  zombi care pierd traseul/urmărirea față de baseline-ul Java;
- PopMan Native este etichetat EXPERIMENTAL până la regresia completă pe dispozitiv;
- ambele rămân toggle-uri reale și persistente;
- nu este declarat niciun fix comportamental în acest checkpoint.
