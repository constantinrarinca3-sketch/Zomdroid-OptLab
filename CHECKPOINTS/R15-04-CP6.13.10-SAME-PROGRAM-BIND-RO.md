## Rezultat

`ShaderHelper.glUseProgramObjectARB(int)` are un fastpath direct și separat.
Fastpath-ul sare întregul apel numai în ramura în care implementarea vanilla ar
ieși fără schimbarea programului:

- optimizarea este activă;
- programul cerut este strict pozitiv;
- programul cerut este identic cu `ShaderHelper.currentlyBound`;
- forma debug necesară există integral;
- `DebugOptions.instance.checks.boundShader.getValue()` este `false`.

`ShaderHelper.currentlyBound` rămâne starea autoritativă. Implementarea nu
introduce un cache sau un shadow state paralel și nu păstrează contoare în
steady-state.

Programul 0 sau negativ, un program diferit, debug bound-shader activ, orice
componentă debug nulă, forma structurală incompatibilă ori o eroare în helper
execută metoda vanilla. O eroare dezactivează numai mecanismul same-program
bind, fără să oprească restul OPT-LAB.
