RUTA REALĂ ȘI FALLBACK
======================

Toggle OFF:
- Pathfind.UseNativeCode=false;
- jocul păstrează implementarea Java PolygonalMap2.

Toggle ON după preflight complet:
- payload copiat atomic ca android/arm64-v8a/libPZPathFind64.so;
- o bibliotecă activă străină este păstrată înainte de înlocuire;
- Pathfind.UseNativeCode=true.

Eșec înainte de pornire:
- opțiunea revine la false;
- jocul pornește pe Java;
- motivul este scris în log și opt-proof.log.

Eșec în runtime:
- agentul scrie PATHFINDING_NATIVE_FALLBACK;
- încearcă să treacă DebugOptions.pathfindUseNativeCode pe false;
- creează markerul one-shot pentru o pornire sigură pe Java;
- findPath nu propagă eroarea nativă către joc.

DOVADA ACTIVE / EXERCISED
=========================

Launcherul scrie:

PATHFINDING_NATIVE_AVAILABLE
PATHFINDING_NATIVE_ACTIVE
PATHFINDING_NATIVE_FALLBACK, când este cazul

Agentul instrumentează PathfindNative.findPath și PathfindNativeThread.runInner.
O terminare normală a apelului nativ scrie:

PATHFINDING_NATIVE_EXERCISED

ACTIVE singur nu este considerat dovadă suficientă.

LIMITA TESTELOR HOST
===================

JAR-urile jocului folosesc bytecode Java 25. Pe hostul Java 17, smoke-testul poate
demonstra că agentul analizează și transformă clasele înainte de respingerea lor de
JVM, dar nu poate executa jocul. Compilarea Android nu a putut fi făcută deoarece
distribuția Gradle 8.13 nu este disponibilă local, iar descărcarea externă este
blocată în acest mediu.

PROTOCOL PENTRU CP1 OFFICIAL PASS
=================================

1. Compilează sideBySideDebug și/sau replaceR1Debug.
2. Instalează pe dispozitiv ARM64 cu pagină de 4096 bytes pentru modulele AB3.
3. Baseline: Pathfinding OFF, celelalte setări identice; pornește jocul și păstrează
   console.txt + opt-proof.log.
4. Candidate: Pathfinding ON; restart complet; reproduce același save/scenariu.
5. Confirmă AVAILABLE=1, ACTIVE=1 și apoi EXERCISED după o cerere reală de traseu.
6. Verifică mișcare zombie, urmărire, obstacole, uși, scări, interior/exterior,
   clădiri, densitate mare și gameplay normal.
7. Compară frame-time, stutter, CPU și stabilitate OFF vs ON fără a schimba altceva.
8. Testează separat persistența Lighting OFF/ON, PZClipper OFF/ON și Pathfinding
   OFF/ON după restart.
9. Confirmă fallback-ul: după eroare/marker, următoarea pornire folosește Java și
   logul explică motivul.
