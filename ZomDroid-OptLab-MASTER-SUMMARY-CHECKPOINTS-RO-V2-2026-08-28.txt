CHECKPOINT 4 - OPTLAB BUILD 42 COMPATIBILITY
============================================================

SCOP
====

Rezolvarea problemei de compatibilitate OptLab cu diferitele patch-uri Build 42.


PROBLEMA
========

OptLab este prea dependent de SHA-ul exact al unui anumit Project Zomboid 42.20.

Exemplu:

42.20 poate funcționa.

Dar:

42.20.1
42.20.2
42.20.3

pot avea alt SHA și OptLab poate rămâne OFF chiar dacă unele optimizări sunt încă perfect compatibile.


ONLY BUILD 42
=============

Adaugă:

Only Build 42

Default recomandat:

ON

Înseamnă:

- OptLab vizează familia Build 42;
- Build 41 și mai vechi nu sunt prioritate.

NU înseamnă:

Build 42 = toate optimizările ON


REGULA CORECTĂ
==============

Build 42
+
feature-ul respectiv este compatibil
=
feature-ul poate fi activat


COMPATIBILITATE INDIVIDUALĂ
===========================

Fiecare optimizare trebuie verificată separat.

Exemplu:

42.20.3

OPT-022 = COMPATIBLE -> ON
OPT-023 = VERIFIED -> ON
OPT-024 = UNSUPPORTED -> OFF

Un feature incompatibil NU trebuie să dezactiveze întreg OptLab.


STĂRI
=====

VERIFIED
= build / SHA deja testat

COMPATIBLE
= SHA-ul general diferă, dar codul necesar feature-ului este compatibil

PROBE
= încă neconfirmat; OFF implicit

UNSUPPORTED
= incompatibil; OFF


SHA
===

Nu elimina verificarea SHA.

SHA exact rămâne util pentru build-uri deja validate.

Dar:

SHA diferit NU trebuie să însemne automat:

tot OptLab OFF.


LOGURI
======

Exemplu:

PZ_VERSION=42.20.3
PZ_BUILD_FAMILY=42
PZ_SHA256=...

ONLY_BUILD_42=ON

OPT022=COMPATIBLE
OPT023=VERIFIED
OPT024=UNSUPPORTED

Dacă un feature este dezactivat:

OPT024_DISABLED reason=TARGET_NOT_COMPATIBLE


PASS
====

- un SHA nou Build 42 nu mai blochează global OptLab;
- fiecare feature are propria compatibilitate;
- fiecare feature are propriul motiv de activare/dezactivare;
- fallback-ul rămâne sigur.


DUPĂ PASS
=========

Creează:

CHECKPOINT-4-BUILD42-COMPAT-SUMMARY.txt
